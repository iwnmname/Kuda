# Kuda

**Рекомендации мест от людей, которым доверяешь.**

Проект сервиса для сохранения и обмена любимыми местами в закрытых кругах.

Kuda помогает ответить на простой вопрос: **«Куда пойти?»**

---

## Проблема

Друзья советуют друг другу кафе, рестораны и другие места в переписках. Через некоторое время сложно вспомнить название, найти сообщение с адресом и понять, кто именно рекомендовал заведение. Когда компания решает, куда пойти, хорошие советы уже разбросаны по разным чатам.

## Решение

Kuda собирает личные рекомендации в закрытых кругах. У каждого места есть адрес, автор и короткий комментарий: почему сюда стоит прийти. Участники круга видят общий список и карту, поэтому могут быстро вернуться к совету друга и выбрать место для встречи.

## Возможности проекта

- **Сохранять рекомендации** заведений с адресом и комментарием.
- **Делиться местами в закрытых кругах** — например, с друзьями, с которыми планируешь выходные.
- **Смотреть рекомендации на карте**, чтобы быстро понять, что есть поблизости или в нужном районе.
- **Выбирать по советам знакомых**, видя, кто именно предложил место и почему.

## Основной сценарий

1. Участник находит заведение, которое хочет посоветовать.
2. Добавляет его в общий круг и пишет короткий комментарий.
3. Друзья видят рекомендацию в списке и на карте.
4. Когда приходит время встретиться, круг помогает выбрать место.

## Текущий этап: интерактивный прототип MVP

Сейчас реализован один демонстрационный круг — **«Куда пойти в выходные»**. В нём можно посмотреть пять тестовых заведений, перейти от отметки на схеме карты к карточке места и добавить собственную рекомендацию. После добавления обновляются список, отметки и счётчик. Интерфейс адаптирован для телефона.

Это локальная демонстрация ключевого сценария. Новые места сохраняются **только до перезагрузки страницы**. Карта пока представляет собой иллюстративную схему без реальных координат. Закрытые круги как система доступа, сервер и база данных в прототипе не реализованы.

## Как запустить демонстрацию

Достаточно открыть `index.html` в современном браузере.

```bash
open index.html
```
